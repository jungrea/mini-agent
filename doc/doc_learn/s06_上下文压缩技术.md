# s06 上下文压缩方法

接历史教程，假设你已经具备本agent基础的数据结构方法，来看看本节上下文压缩方法。

我们知道上下文长度的大小是大模型的一个很重要的指标，一旦上下文过长以后，模型记不住那么多的信息就会出现回复结果差、幻觉严重等问题。本篇主要围绕上下文过程来阐述各类上下文压缩方法。

### 1. 什么是上下文以及上下文的变化
所谓上下文，就是这一轮输入输入到模型中的对话内容。用我们之前调用的通用接口来看：
```
response = client.messages.create(
            model=MODEL,
            system=SYSTEM,
            messages=messages,
            tools=TOOLS,
            max_tokens=8000,
        )
```
某一次和大模型对话的`messages`内容就是这一次的上下文。过往文章可以发现，随着一个对话窗口的打开，`messages`内容在一轮轮循环中一直增加。就比如下面这个，`agent_loop(history)`是一次内部循环的对话解决内容，而多轮对话的`history`一直在append，随着对话的增加就会越来越大，越长的对话模型越难理解，最终无法得到我们想要的结果。
```python
history: list[Any] = []
while True:
    try:
        query = input("\033[36ms02 >> \033[0m")
    except (EOFError, KeyboardInterrupt):
        break
    if query.strip().lower() in ("q", "exit", ""):
        break
    history.append({"role": "user", "content": query})
    agent_loop(history)
    response_content = history[-1]["content"]
    for block in response_content:
        if hasattr(block, "text"):
            print(block.text)
```

那么应该如何解决上下文越来越长的问题呢？常规的想法：
（1）对话的`history`我保留最近几轮不就好了，这个方法可以，但是无法记住历史的关键信息；
（2）对话历史进行一定程度的压缩，如何压缩，压缩方法成为关键。
（3）取一个折中，一定范围大小内的上下文不压缩，触发一定大小再压缩，这也是一个方法。

### 2. 如何压缩

由浅到深，压缩方法分为：
```text
第 1 层：对特别大结果不直接塞进上下文
  -> 写到磁盘，只留预览

第 2 层：对历史很远的结果不一直原样保留
  -> 替换成简短占位

第 3 层：如果当前包括历史部分对话后还是太长
  -> 主动、被动的生成一份压缩摘要
```

说说该教程里面的方法。

#### 2.1. 历史比较久的结果直接丢弃
比如说在每次循环调用工具的过程中，工具都会产生一些结果，那么每一次我们只保留最近几个工具的一个结果，把那些历史上已经比较久远的工具的结果给去掉。那么一个核心的代码如下：
```python
def micro_compact(messages: list) -> list:
    # 第一步：收集所有 tool_result 工具结果块
    tool_results = collect_tool_result_blocks(messages)
    
    # 第二步：如果工具结果数量 ≤ 保留数量，直接返回原消息，不做任何压缩
    if len(tool_results) <= KEEP_RECENT_TOOL_RESULTS:
        return messages

    # 第三步：只压缩【最早的、多余的】工具结果，保留最近 N 条
    # 除了最后N条之外的所有旧结果
    for _, _, block in tool_results[:-KEEP_RECENT_TOOL_RESULTS]:
        content = block.get("content", "")
        
        # 不压缩的条件：不是字符串 / 内容长度≤120（短文本没必要压缩）
        if not isinstance(content, str) or len(content) <= 120:
            continue
        
        # 第四步：满足压缩条件 → 把长内容替换成固定提示文字
        block["content"] = "[Earlier tool result compacted. Re-run the tool if you need full detail.]"
    
    # 返回压缩后的消息列表（原列表被修改，结构不变，只是旧长结果被替换）
    return messages
```
那么这里就实现了对于工具调用结果的上下文的裁剪。

#### 2.2. 当上下文的token达到设置的阈值后被动压缩
对于这一块，我们有一个全局变量来表示允许上下文的最大token量。比如说：
`
CONTEXT_LIMIT = 50000
`
那么每一轮循环的过程中，我们就统计当前上下文总的词量是否达到了这个上限。那如果达到了这个上限呢？我们就进行一次被动的压缩。

这里就涉及到压缩方法，教程中的压缩方法是直接把大模型当做压缩方法，给它输入上下文，让它输出压缩后的内容。核心的一个函数如下：
```python
def summarize_history(messages: list) -> str:
    conversation = json.dumps(messages, default=str)[:80000]
    prompt = (
        "Summarize this coding-agent conversation so work can continue.\n"
        "Preserve:\n"
        "1. The current goal\n"
        "2. Important findings and decisions\n"
        "3. Files read or changed\n"
        "4. Remaining work\n"
        "5. User constraints and preferences\n"
        "Be compact but concrete.\n\n"
        f"{conversation}"
    )
    response = client.messages.create(
        model=MODEL,
        messages=[{"role": "user", "content": prompt}],
        max_tokens=2000,
    )
    return response.content[0].text.strip()

```
可以看到，在这个函数里面，新起了一个对话，直接把message当做输入，prompt当做一个压缩的方法，然后让大模型进行一次压缩。其实现在很多主流的agent压缩方法基本上都是这样，直接使用大模型进行压缩。

#### 2.3. 用户主动进行压缩
除了上面说的，当上下文达到上限的时候系统被动压缩以外，那么用户也可以主动调用命令或者在对话中直接对话表示要进行压缩也能够实现上下文的压缩。那么大模型是如何解析用户的对话命令之后执行压缩呢？这里就可以将“压缩命令”本身作为一个工具来匹配用户的一个输入。

因此首先用户需要定义一个压缩工具，和前面的工具章节类似：
```python
TOOLS = [
    {
        "name": "compact",
        "description": "Summarize earlier conversation so work can continue in a smaller context.",
        "input_schema": {
            "type": "object",
            "properties": {
                "focus": {"type": "string"},
            },
        },
    },
]
```
那么定义了这样的一个工具给大模型，当大模型匹配到要调用压缩工具的时候，我们就去灵活地处理这个代码实现压缩，比如像下面这个样子：
```python
for block in response.content:
    if block.type != "tool_use":
        continue

    output = execute_tool(block, state)
    if block.name == "compact":
        messages[:] = compact_history(messages, state, focus=compact_focus)
```
也就是在代码里面主动的去判断工具的类型，如果是压缩工具，就直接复用压缩函数`compact_history`即可。

这次代码里面实现了历史记录的丢弃，程序自动压缩，以及人工主动压缩的这样的一个功能。

### 3. 细看一次对话后的内部循环
```python
def agent_loop(messages: list, state: CompactState) -> None:
    # 无限循环：持续处理对话，直到模型返回最终回答（非工具调用）
    while True:
        # 1️⃣ 轻量级微型压缩：只压缩旧的、长的 tool_result（替换成提示文字）
        messages[:] = micro_compact(messages)

        # 2️⃣ 估算上下文大小，如果超过模型限制 → 执行深度压缩
        if estimate_context_size(messages) > CONTEXT_LIMIT:
            # 深度压缩历史（删除/合并早期消息）
            messages[:] = compact_history(messages, state)

        # 3️⃣ 调用 AI 大模型接口，获取回复
        response = client.messages.create(
            model=MODEL,          # 使用的模型
            system=SYSTEM,        # 系统提示词
            messages=messages,    # 传入当前对话历史
            tools=TOOLS,          # 模型可调用的工具列表
            max_tokens=8000,      # 生成内容最大长度
        )

        # 4️⃣ 将模型的回复内容加入对话历史
        messages.append({"role": "assistant", "content": response.content})

        # 5️⃣ 如果模型停止原因不是「需要调用工具」→ 结束循环
        if response.stop_reason != "tool_use":
            return

        # ------------------------------
        # 下面开始：模型需要调用工具 → 执行工具
        # ------------------------------
        results = []            # 存放所有工具执行结果
        manual_compact = False  # 标记：是否触发了手动压缩工具
        compact_focus = None    # 手动压缩的关注点（主题）

        # 遍历模型回复里的所有内容块
        for block in response.content:
            # 只处理工具调用类型的块
            if block.type != "tool_use":
                continue

            # 执行对应的工具，获取输出
            output = execute_tool(block, state)

            # 如果调用的工具是「compact」（手动压缩），打上标记
            if block.name == "compact":
                manual_compact = True
                compact_focus = (block.input or {}).get("focus")

            # 把工具执行结果包装成 tool_result 格式
            results.append({
                "type": "tool_result",
                "tool_use_id": block.id,  # 关联对应的工具调用ID
                "content": str(output),   # 工具返回内容
            })

        # 6️⃣ 把所有工具执行结果作为「用户消息」加入对话历史
        messages.append({"role": "user", "content": results})

        # 7️⃣ 如果触发了手动压缩工具 → 立即执行深度压缩
        if manual_compact:
            print("[manual compact]")
            messages[:] = compact_history(messages, state, focus=compact_focus)
```
这样一个简单的循环中的多次压缩就实现了。
