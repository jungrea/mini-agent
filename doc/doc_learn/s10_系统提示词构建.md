# s10_系统提示词构建

本节我们看看系统提示词相关的内容。系统提示词就是给Agent的一个角色画像、功能描述、规则约束等，好的系统提示词对于任务的准确完成也是非常重要的。

## 1. 系统提示词规范化编排

截止到现在，我们已经学习了Agent的较多模块，其中有些模块已经自带了一些prompt到系统提示词中，比如说工具列表，skill，记忆系统等，而这些子模块本身可能一直增长，这就导致我们的拼接合并的系统提示词会越来越大。

所以到了这个阶段，system prompt 不能再当成一块硬编码文本。它应该升级成：由多个来源共同组装出来的一条流水线。细分一下可以包括如下几个部分：

### 1.1 system prompt
system prompt 是给模型的系统级说明,通常是一个比较固定的模块。

它通常负责告诉模型：

- 你是谁
- 你能做什么
- 你应该遵守什么规则
- 你现在处在什么环境里

### 1.2 组装流水线
除了系统提示词，还有比如说工具、skill的这种prompt。这种通常情况下也比较固定，但是它应该作为一个单独的类别来加到prompt里面，我们可以有一个prompt的组装流水线，它完成的功能包括：
- 不同信息来自不同地方
- 最后按顺序拼接成一份输入

它不是一个死字符串，而是一条构建过程。

### 1.3 动态拼接信息

有些信息经常变化，例如：

- 当前日期
- 当前工作目录
- 本轮新增的提醒

这些信息不适合和所有稳定说明混在一起。

我们可以把 system prompt 想成 6 段：

```text
1. 核心身份和行为说明
2. 工具列表
3. skills 元信息
4. memory 内容
5. CLAUDE.md 指令链
6. 动态环境信息
```

然后按顺序拼起来：

```text
core
+ tools
+ skills
+ memory
+ claude_md
+ dynamic_context
= final system prompt
```
这么拆分的好处是：
* 各个模块清晰明了；
* 好维护好测试；
* 方便自由添加，动态和静态promot分离；

## 2. 模块实现

有了上面的模块拆分，那么在实现上其实就比较简单了。因为每一个模块都对应了我们历史上的一个章节，而对应章节里面的prompt又是非常清晰的，在这一章节里面，只需要把各个章节的提示词汇总起来，作为一个新的SystemPromote类就可以了。

这里直接贴上代码的核心架构：

```
class SystemPromptBuilder:
    """
    从独立模块拼装系统提示词（System Prompt）
    模块化设计 = 易理解、易测试、易扩展
    """

    def __init__(self, workdir: Path, tools: list):
        # 初始化路径与依赖
        self.workdir = workdir    # 工作目录
        self.tools = tools        # 可用工具列表
        self.skills_dir = workdir / "skills"   # 技能目录
        self.memory_dir = workdir / ".memory"  # 记忆目录

    # ------------------------------
    # 核心模块：6 大提示词组成部分
    # ------------------------------

    def _build_core(self) -> str:
        """模块1：核心身份指令（你是谁、要做什么）"""
        pass

    def _build_tool_listing(self) -> str:
        """模块2：可用工具清单（函数/能力列表）"""
        pass

    def _build_skill_listing(self) -> str:
        """模块3：技能清单（skills/ 目录下的专业能力）"""
        pass

    def _build_memory_section(self) -> str:
        """模块4：持久记忆（.memory/ 中的长期记忆）"""
        pass

    def _build_claude_md(self) -> str:
        """模块5：多层级规则指令（全局/项目/目录级配置）"""
        pass

    def _build_dynamic_context(self) -> str:
        """模块6：动态上下文（日期、目录、平台等实时信息）"""
        pass

    # ------------------------------
    # 总入口：拼接所有模块
    # ------------------------------

    def build(self) -> str:
        """
        按顺序组装完整 Prompt：
        1.核心指令 → 2.工具 → 3.技能 → 4.记忆 → 5.规则 → 【分割线】 → 6.动态上下文
        """
        sections = [
            self._build_core(),
            self._build_tool_listing(),
            self._build_skill_listing(),
            self._build_memory_section(),
            self._build_claude_md(),
            DYNAMIC_BOUNDARY,  # 静态/动态内容分割
            self._build_dynamic_context()
        ]
        return "\n\n".join(sections)
```
